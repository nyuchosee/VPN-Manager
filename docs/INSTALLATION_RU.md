# Установка и обновление: справочник

## Перед началом

Требуются Linux с `systemd`, Python 3.10+ и `venv`, `sudo`, рабочая панель 3x-ui с HTTPS API, токены Telegram и 3x-ui и идентификатор администратора Telegram. ID Inbound должны соответствовать существующим активным подключениям, например `1,2` (условный пример). Для подписок нужен HTTPS-шаблон с `{sub_id}`, например `https://sub.example.org/sub/{sub_id}`.

Установщик запускается в **интерактивном терминале** и не принимает токены через аргументы командной строки. Для локальной установки используйте `dist/vpn-manager-setup-0.5.2.sh`; для сетевой загрузки подставьте свою пару `OWNER/REPOSITORY` в инструкции README.

## Процедура

```bash
(cd dist && sha256sum -c SHA256SUMS)    # в корне клонированного репозитория
bash dist/vpn-manager-setup-0.5.2.sh --verify
sudo bash dist/vpn-manager-setup-0.5.2.sh
sudo systemctl status vpn-bot --no-pager -l
sudo vpn-manager-probe
sudo vpn-manager-doctor --api
```

При первой установке мастер запрашивает шесть параметров (Telegram Bot Token, Telegram ID администраторов, HTTPS URL и API Token панели, Inbound IDs, шаблон URL подписки) и создаёт конфигурацию `/etc/vpn-bot/bot.env`, виртуальное окружение, базу в `/var/lib/vpn-bot`, непривилегированную службу `vpn-bot.service` и служебные команды. Запись в 3x-ui отключена (`WRITE_ENABLED=false`). Для установки пакетов Python требуется исходящий доступ к репозиторию пакетов.

Для обновления действующей установки выполните **до запуска**:

```bash
sudo vpn-manager-write-mode --disable
sudo vpn-manager-backup --all
```

Затем повторно запустите установщик из нового релиза. Мастер предложит обновление и сохранит предыдущую конфигурацию и базу заявок. Откатные копии размещаются в `/var/backups/vpn-manager/`. Обновление останавливает/перезапускает только `vpn-bot`; оно не переустанавливает панель.

## Тест и удаление

```bash
sudo vpn-manager-doctor --api
sudo journalctl -u vpn-bot -n 60 --no-pager
sudo vpn-manager-write-mode --disable
sudo vpn-manager-uninstall
```

Перед включением записи проверьте на отдельном тестовом клиенте создание, продление, блокировку и HWID. Не повторяйте операции с `needs_review` без сверки клиента непосредственно в панели. Скрипт удаления удаляет локальную установку и данные бота после подтверждения, но не удаляет клиентов из 3x-ui; бэкапы по умолчанию сохраняются. Разрешение на удаление архивов — отдельный вопрос мастера.

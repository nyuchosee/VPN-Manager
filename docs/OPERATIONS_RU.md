# Эксплуатация VPN Manager: справочник команд

## Пользовательское меню

`/start` — главное меню и новый видимый экран; `/id` — показать Telegram ID; `/help` — помощь; `/cancel` — отменить текущий ввод. Через кнопки доступны заявка на доступ, продление, просмотр текущего срока и подписки, устройства/HWID и тикеты поддержки. Трафик в гигабайтах не показывается в пользовательской карточке. Система уведомлений по оплате отсутствует.

## Администратор

| Команда | Назначение |
|---|---|
| `/admin` | Основное меню администратора |
| `/client TG_ID` | Карточка привязанного клиента |
| `/lookup ЧАСТЬ_ИМЕНИ` | Поиск клиента через API панели |
| `/alias TG_ID ИМЯ` | Установить отображаемый псевдоним, не изменяя UUID и техническое имя в панели |
| `/bind TG_ID CLIENT_EMAIL` | Связать Telegram ID с существующим клиентом |
| `/unlink_missing TG_ID` | Снять устаревшую связь после подтверждения отсутствия клиента в API панели |
| `/grant TG_ID 30` | Создать административную заявку на доступ |
| `/ops` | Показать операции, требующие ручной сверки |
| `/resolve REQUEST_ID approved\|rejected` | Ручное разрешение после проверки клиента в панели |
| `/diag`, `/writecheck` | Диагностика и режим записи |
| `/tickets`, `/ticket ID` | Список/просмотр тикетов |
| `/close_ticket ID` | Закрыть тикет и попытаться удалить сообщения |
| `/ticket_cleanup ID` | Повторить очистку доступных для удаления сообщений |
| `/helpadmin` | Справка по командам администратора |

Из карточки доступны заявки на изменение срока и трафика, блокировку/разблокировку, настройку HWID и подтверждаемое удаление клиента из 3x-ui. Назначение срока в днях **заменяет** действующий срок; отсчёт идёт от одобрения, либо администратор указывает конкретную дату UTC. Для перехода с бессрочного срока в срочный требуется отдельное подтверждение. Действия записи доступны только после включения режима и проверки API.

## Служебные команды Linux

| Команда | Назначение |
|---|---|
| `sudo vpn-manager-configure` | Изменить API, токены или шаблон подписки; запись отключается |
| `sudo vpn-manager-inbounds` | Выбрать Inbound для новых клиентов |
| `sudo vpn-manager-probe` | Проверка API без изменения клиентов |
| `sudo vpn-manager-doctor --api` | Проверка системных прав, базы, зависимостей и API |
| `sudo vpn-manager-backup --all` | Бэкап данных приложения и обнаруженной конфигурации панели |
| `sudo vpn-manager-write-mode --disable` | Запретить операции изменения |
| `sudo vpn-manager-write-mode --enable` | Разрешить запись с подтверждением и резервированием |
| `sudo systemctl restart vpn-bot` | Перезапуск бота |
| `sudo journalctl -u vpn-bot -n 50 --no-pager` | Журнал ошибок |
| `sudo vpn-manager-uninstall` | Удаление локального бота с подтверждением |

Тикеты хранят идентификаторы пересылаемых сообщений для удаления при закрытии. Telegram ограничивает срок удаления (обычно 48 часов), поэтому гарантировать удаление всей переписки нельзя.

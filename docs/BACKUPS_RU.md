# Резервирование и восстановление: справочник

Бэкапы сохраняются в `/var/backups/vpn-manager/` с ограниченными правами. Архивы могут содержать API-токены, сертификаты, ссылки подписок и пользовательские данные; **не добавляйте их в Git** и храните шифрованную копию вне сервера.

```bash
sudo vpn-manager-backup --bot      # локальные данные бота и конфигурация
sudo vpn-manager-backup --panel    # копия базы 3x-ui и обнаруженных настроек
sudo vpn-manager-backup --all      # оба набора
sudo ls -la /var/backups/vpn-manager/
```

Онлайн-копии SQLite выполняются механизмом резервного копирования SQLite с проверкой `integrity_check`. Для выбранного набора файлов создаётся `SHA256SUMS`, который можно проверять так:

```bash
cd /var/backups/vpn-manager/ИМЯ_АРХИВА
sudo sha256sum -c SHA256SUMS
```

Не восстанавливайте живую SQLite копированием файла поверх запущенного бота. При необходимости остановите службу, сохраните текущие данные и восстановите базу/конфигурацию из заведомо корректной резервной копии с сохранением владельцев и прав; затем проверьте `vpn-manager-doctor`. Для полного аварийного восстановления панели используйте также соответствующий механизм резервного копирования самой 3x-ui и nginx/сертификатов. Процедура восстановления зависит от конкретной инфраструктуры, поэтому универсальная команда автоматического восстановления намеренно не приводится.

Удаление бота не означает удаление его прежних изменений клиентов в панели. Перед обновлением отключайте запись и создавайте независимую копию.

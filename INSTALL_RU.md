# Установка и обновление VPN Manager

Инструкция для установки с GitHub через `git clone` и автономный установщик из каталога `dist/`. Все команды выполняются на VPS в интерактивном SSH-терминале. Инструкция не содержит параметров конкретного сервера.

## 1. Перед установкой

1. Подготовьте работающую панель 3x-ui с HTTPS API, отдельного Telegram-бота, Telegram ID администратора, включённые Inbound и HTTPS-шаблон ссылки подписки с `{sub_id}`.
2. Убедитесь, что доступны Linux с `systemd`, Python 3.10+, модуль `venv`, `sudo` и `git`. Для установки Git на Ubuntu/Debian при необходимости выполните:

   ```bash
   sudo apt-get update
   sudo apt-get install -y git
   ```

3. Создайте резервную копию панели 3x-ui. Если VPN Manager **уже установлен**, перед обновлением выполните:

   ```bash
   sudo vpn-manager-write-mode --disable
   sudo vpn-manager-backup --all
   ```

## 2. Получение проекта с GitHub

Замените `OWNER/REPOSITORY` на владельца и имя публичного репозитория. Команды клонируют ветку `main` в каталог `vpn-manager` и переходят в него:

```bash
git clone --depth 1 --branch main https://github.com/OWNER/REPOSITORY.git vpn-manager
cd vpn-manager
```

Если каталог `vpn-manager` уже существует и связан с нужным репозиторием, **не клонируйте его повторно**. Перейдите в него и получите обновления:

```bash
cd vpn-manager                    # из родительского каталога
git pull --ff-only origin main
```

## 3. Проверка и запуск установщика

В корне клонированного репозитория выполните:

```bash
(cd dist && sha256sum -c SHA256SUMS)
bash dist/vpn-manager-setup-0.5.2.sh --verify
sudo bash dist/vpn-manager-setup-0.5.2.sh
```

Первая команда сверяет контрольную сумму установщика с файлом `dist/SHA256SUMS`, вторая проверяет встроенный архив, третья запускает интерактивный мастер. Проверка контрольной суммы подтверждает соответствие файлов друг другу, но не заменяет проверку доверия к источнику репозитория.

При первой установке мастер запросит токен Telegram, ID администратора, HTTPS URL и API Token панели 3x-ui, ID существующих Inbound и шаблон подписки. Секреты вводятся без отображения. Установщик делает резервную копию панели, создаёт системную службу и проверяет API **без записи** (`WRITE_ENABLED=false`).

## 4. Проверка после установки

```bash
sudo systemctl status vpn-bot --no-pager
sudo vpn-manager-probe
sudo vpn-manager-doctor --api
sudo journalctl -u vpn-bot -n 50 --no-pager
```

Проверьте `/start` и `/admin` в Telegram, затем работу с отдельным тестовым клиентом 3x-ui. Включайте операции записи только после проверки совместимости через `sudo vpn-manager-write-mode`.

## 5. Обновление установленного бота

1. Отключите запись и создайте резервную копию командами из раздела 1.
2. Обновите код через `git pull --ff-only origin main` из каталога клонированного репозитория.
3. Повторите проверку контрольной суммы и встроенного архива из раздела 3.
4. Запустите `sudo bash dist/vpn-manager-setup-0.5.2.sh` **или файл с новой версией**, если он появился в каталоге `dist/`.
5. Проверьте состояние службы и работу API командами из раздела 4.

Повторный запуск установщика обнаруживает установленный экземпляр и предлагает обновление, сохраняя конфигурацию и SQLite. Рабочую базу не удаляйте. Установщик не создаёт публичных портов для Telegram и не переустанавливает 3x-ui, Xray или nginx.
